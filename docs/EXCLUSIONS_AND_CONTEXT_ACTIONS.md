# 0.5.4 自动排除与右键快捷入口

## 行为

- 可按标签排除自动处理，标签按完整名称匹配，不区分大小写。
- 可在文件夹右键菜单排除该文件夹；规则同时覆盖其子文件夹。
- 排除只影响自动任务。文献或文件夹右键菜单中的 L1、L2、L3 手动任务仍可运行。
- 新增排除规则时，尚未完成的自动任务会标记为 `automation-excluded` 并取消；已完成笔记不变。
- 移除排除规则后，自动化处于运行状态时会重新检查受影响文献，不重复建立同一任务。

## 使用入口

1. 打开 Literature Flow 面板，在“自动排除”中维护排除标签。
2. 在 Zotero 左侧文件夹上右键，选择“排除此文件夹自动处理”或“恢复此文件夹自动处理”。
3. 在文献或文件夹上右键，直接选择“按当前评分补齐”或“补齐至 L1 / L2 / L3”。

界面的“当前选择”表会显示每篇文献是否命中自动排除规则。任务表会把被规则取消的任务说明为“符合自动排除规则”。
