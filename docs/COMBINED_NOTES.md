# 0.4.0：一篇文献一条综合笔记与 Markdown

2026-10-23（Asia/Shanghai）在 P520 Zotero 9.0.1 完成迁移与原生验证。

## 使用方式

后续生成结果保存在同一条 `[Literature Flow] 综合阅读` 子笔记中，按 L1 概览、L2 证据卡、L3 深度阅读排列。只更新本次级别，其他级别的内容和人工补充保持原样。明确重生成某级会替换该级，写入前保存整个父条目的笔记快照。

模型输出按 Markdown 解析，在 Zotero 中呈现为可编辑的富文本；支持标题、加粗、嵌套列表、引用、代码块和表格。Zotero 原生笔记仍以 HTML 保存。“导出综合笔记 Markdown”使用 Zotero 原生 Note Markdown 翻译器导出当前笔记，包含人工修改，移除内部任务记录。不是仅导出原始模型响应。

已有文献可选择“整合已有笔记（不调用模型）”。完整结果复用并按级别合并，不重新推理。默认保留旧 LF 笔记正文，加 `LF:Archive` 标签；原 Butler 笔记不改写。保留历史备份意味着条目下仍能看到原笔记，但后续只维护综合笔记。冲突、未知结构、并发修改会停止写入，提示核对。

## 实现与保护

- 综合笔记具有 `LF:Note`、`LF:Combined` 标签，末尾保留各级独立任务记录。完成检查识别同一笔记中的多个级别；重试、恢复和再次整合不重复创建笔记。
- 前置结果使用级别任务 ID 和 revision 标识。旧缓存仍能通过 originKey 匹配，更新同一综合笔记中的其他级别不会误判前置结果已更换。
- 未修改的旧 LF 正文可从已经校验的原始响应恢复 Markdown 排版；有人工修改时保留当前 HTML。旧 Butler 完整级别提取为文本副本，原始笔记保留，复杂旧排版不保证原样复制。
- 写入前先保存 profile 下 `literature-flow-v1/note-backups/` 私有快照；事务中重新检查权限、评分及全部原笔记内容和标签。与读取快照不一致时拒绝写入。
- 包内使用经官方 npm 完整性校验的 markdown-it 14.1.0（MIT），来源、许可和哈希见 `addon/content/lib/README.md`。禁止原始 HTML，图片仅显示文字说明，链接限 HTTP(S)/mailto；模型标题在 h4–h6，L1–L3 分隔为 h3，不占用 Butler 的 h1/h2。
- 冻结提示词不变；既有 output-tags-json 缓存恢复修复保留。
