# 0.5.5 跨设备手动提交

P520 保持唯一 executor。其它装有 0.5.5 的 Zotero 设备保持“阅读／待机”，在文献或文件夹右键菜单选择“按评分补齐”或“补齐至 L1/L2/L3”。待机设备将带唯一编号的 `LF:Request:Lx:<UUID>` 标签写入文献，随 Zotero 数据同步传递。

P520 在通知及周期检查中识别请求，按手动模式入队，因此可覆盖自动排除和评分限制。接收记录保存在 P520 的本机状态中，重复同步不会重复推理。L1–L3 仍按顺序更新同一条综合笔记。目标级别完成后，P520 清除请求标签，笔记随 Zotero 同步回其它设备。

前提是两端同步同一个可写 Zotero 文献库，P520 正在运行并装有 0.5.5。提交后在“当前选择”中可看到“已提交至 P520”；队列详情和失败重试仍在 P520 的任务表。若文献存在待核对或冲突结果，请先在 P520 核对；请求标签会保留。同步请求不是跨设备执行锁，不能同时启用第二个 executor。
