## 明确缺口

1. 生产 Note 抽样只读查询返回 `database is locked`，未强制解锁或继续读取；没有拿到真实 Note 样例。现有识别器有合成样例测试，不能据此宣布全部历史格式兼容。
2. 本轮没有安装 XPI，也未在隔离 Zotero 实例做 UI/生命周期/同步验收。manifest 的 9.0.x 是预览安装目标，不是“已实测支持”的声明。
3. 只验证模型列表，没有验证完整文本推理。P520 本机的回环地址不能原样用于 Mac；另一设备需填写可访问的 P520 主机地址。
4. 当前固定提示词包；未实现 UI 动态导入提示词和自动版本迁移。共享配置导入只导入模型名称和契约标识。
5. 仅发送文本，不调用 MinerU、不给图片路径冒充视觉输入；Markdown 完整性需用户明确确认。PDF 索引页数完整仍不等于图表/文字提取质量完美。
6. 当前格式渲染以安全的段落/三级标题为主；复杂 Markdown 表格、数学排版和图片不是本版富文本验收目标。
