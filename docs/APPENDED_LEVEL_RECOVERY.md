# 0.5.1 前置级别识别修复

P520 现场发现，AI Butler 会把不同时间生成的 L1、L2 内容追加到同一个 Note，且顺序不固定。0.5.0 仅在首个 L2/L3 之前识别 L1，因此“L2 在前、L1 在后”的有效旧笔记会被误判为 L1 待核对，使自动 L3 长期停在“等待前一级结果”。

0.5.1 按 AI Butler 的独立生成块逐块识别 L1，不再依赖追加顺序。若前置级别确有冲突、被删除或结构不完整，后续级别不再被错误规划；已经存在的下游任务会显示“前一级结果需核对”，而不是无限等待。

实机回归条目为 `FE8MUC5P`。其旧 Note 中 L2 位于前部、L1 位于后部，升级后应同时识别为完整，并允许已有 L3 自动任务继续执行。
