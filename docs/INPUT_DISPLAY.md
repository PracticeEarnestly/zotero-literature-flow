# 0.4.5 输入状态显示

## 修改

Literature Flow 的只读预览原先直接显示内部输入对象，例如：

```text
{"mode":"PDF_TEXT","characters":48123,"coverage":{"indexedPages":11,"total":11}}
```

0.4.5 将其显示为：

```text
Zotero PDF 全文 · 48,123 字符 · 已索引 11/11 页
```

这是一条输入来源与索引覆盖率说明，不是任务错误。等待全文、索引不完整等状态仍显示为明确的中文原因。
