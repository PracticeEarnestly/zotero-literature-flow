# 0.3.5：修复 output-tags-json 并恢复已存结果

2026-10-23（Asia/Shanghai）在 P520 完成。

## 原因与修复

失败的 L2 响应正常结束（`finish_reason: stop`），正文及所需章节完整，但标签 JSON 使用了 `“ ”` 弯引号；部分键还混用了弯引号开头与 ASCII 引号结尾。0.3.4 直接调用 `JSON.parse`，因此报 `output-tags-json`。

0.3.5 先尝试标准 JSON。仅在失败时识别字符串边界的弯引号，转换后仍交给标准解析器，并继续执行原有结构、章节、证据级别和允许标签校验。不会修补缺失括号、尾逗号、单引号或推测内容；有效 JSON 字符串和正文内的引号保留。冻结提示词未改动。

## 无需重复推理的恢复

任务表对有缓存的此类失败显示 **检查已存结果**。该操作优先处理缓存，不增加请求次数，不改变任务 generation；保存前仍核对原文哈希、前置 Note、评分、权限及已有结果。缓存丢失或不一致时停止，绝不自动转为模型请求。用户明确选择 **重新请求** 才走原来的失败重试路径。
