# Collection 右键任务与合并进度 · 0.4.7

Literature Flow 0.4.7 为 Zotero collection 右键菜单增加任务子菜单，并修复分类批量合并看似“没有反应”的问题。

## Collection 右键任务

在 collection 上右键选择“Literature Flow · 选择任务”，可直接选择：

- 查看状态与任务表；
- 检查本分类（只读）；
- 按当前评分补齐缺失；
- 补齐至 L1 概览；
- 补齐至 L2 证据卡；
- 补齐至 L3 深读；
- 合并 AI 笔记（先预览）。

L1–L3 与按评分补齐会先打开范围和任务确认，不会仅因展开右键菜单而调用模型。合并入口只生成预览；仍需点击“确认合并并移入回收站”才写入。

## 无响应问题及修复

0.4.6 的合并预览只显示包含明确 AI 来源笔记的文献，但最终执行再次遍历整个 collection。如果最先遇到的文献没有可合并结果，执行会停止。同时按钮在等待期间没有即时状态，分类操作还会重复读取全文，因此用户难以判断是否开始。

0.4.7 采用预览中的精确文献 ID 执行，并在后端再次跳过没有明确来源笔记的文献。合并不再重复读取整类 PDF 全文。界面持续显示：

1. 核对最新笔记；
2. 保存私有备份；
3. 写入综合笔记；
4. 将来源笔记移入回收站；
5. 当前篇数、总篇数和文献标题；
6. 全部完成或停止原因。

合并期间确认和关闭按钮会锁定，避免重复提交。发生错误时保留预览，并显示停止原因。
