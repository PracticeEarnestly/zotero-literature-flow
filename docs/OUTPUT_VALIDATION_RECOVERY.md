# 0.5.3 输出校验恢复

本版本处理模型长输出中两类可恢复的格式偏差：必需章节内重复字段名，以及 `Evidence Boundary` 子标题与父标题使用同一 Markdown 层级。校验器只把后续必需章节识别为边界，仍要求每个必需章节包含实际正文。

若完整 L3 正文缺少整个 Zotero 标签区块，但正文明确且唯一地给出 E0–E5 证据等级，插件只恢复对应的白名单 `Evidence:E#` 标签。部分边界标记、矛盾等级、L1/L2 标签缺失和非法 JSON 仍会失败，不会猜测标签。

升级后，插件会对已有的输出校验失败任务执行一次已保存响应复检，不调用模型。复检仍不通过的任务保持失败，不会在每次启动时循环重试。

P520 的三份真实失败响应已作为私有回归输入验证：两个章节格式误判和一个完整 L3 漏标签区块均可通过新校验，且保留原始模型响应与尝试次数。
